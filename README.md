# akari's cool qr code generator

A browser-based QR code generator built with React and Tailwind CSS.

Live demo: https://azideu.github.io/qrcodegenerator/

## Features

- URL input with instant preview
- High-res PNG export (512px, 1024px, 2048px) and SVG vector export
- Batch mode to generate multiple QR codes at once as a ZIP file
- Local history saving in the browser
- Works on mobile and desktop
- Runs entirely client-side with no servers or tracking

## Local setup

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run deploy
```
